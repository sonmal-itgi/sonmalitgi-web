# 단계별 아이콘

현재 아이콘은 로고의 초록색 계열(#139B72)만 사용한 SVG 선 아이콘입니다.
그라데이션·그림자·광택·반짝임 없이 같은 굵기의 둥근 선으로 직접 제작했습니다.

- 초급: 새싹 — frontend/public/icons/levels/beginner.svg
- 중급: 책 — frontend/public/icons/levels/intermediate.svg
- 고급: 깃발 — frontend/public/icons/levels/advanced.svg

기존 생성형 PNG 아이콘은 이 단순한 SVG 아이콘으로 교체했습니다. 원본 손말잇기 로고는 그대로 유지합니다.
