# 운전 주먹 수형 실시간 안내

운전 단계에서 두 손 좌표를 검사하고 여러 손가락이 명확히 펴졌을 때 굽힘 안내를 제공한다. 새로운 학습 모델 없이 관절 기하를 비교하는 규칙 기반 기능이다. LSTM의 예측·통과 점수에 영향을 주지 않는다. 기존 MLP 후보는 계속 비활성 상태이며 이번 규칙과 구분한다.

## 기준과 판정

- 21개 좌표의 x·z는 영상 너비, y는 높이로 축척 보정한다. MediaPipe 추정 깊이는 실제 측정 깊이가 아니다.
- 엄지를 제외한 네 손가락의 PIP·DIP 각도와 손목~손끝 거리를 검사한다.
- 굽힌 기준 PIP 상한 110도에 35도 여유를 둬 PIP >145도, DIP >140도, 손목~손끝 거리 / 손목~PIP 거리 >1.12인 손가락을 명확히 펴진 것으로 취급한다.
- 적어도 두 손가락이 이 조건을 충족하는 손이 있을 때만 안내한다. 엄지·한 손가락의 미세 오류는 평가하지 않는다.
- 이 값들은 보수적 시작 설정이며 정상 영상에서 통계적으로 학습한 분류 경계가 아니다. 기존 정상 운전 촬영 자료로 불필요한 안내 여부만 로컬 확인했다. 오류 동작에 대한 실제 탐지 성능은 미검증이다.
- 양손 모두 완전한 좌표가 있어야 한다. 화면 가장자리, 작은 손, 붕괴된 뼈 길이, 손바닥 추정 면이 거의 옆으로 향한 경우 교정을 보류한다. 가림·깊이 추정 오류를 모두 검출할 수 있는 것은 아니다.
- 기존 촬영 안내를 우선하고, 수형 문제가 약 800ms 지속돼야 표시한다. 관측 공백이 500ms를 넘거나 정상으로 회복되면 초기화한다.
- 첫 ‘운전’ 인식 후 ‘천천히/빨리’ 단계에서는 수형 안내를 중지한다. 사전·다른 표현에는 적용하지 않는다.

메시지: “운전은 두 손을 주먹 모양으로 표현해요. 펴진 손가락을 조금 더 굽혀 보세요.”

## 검증 범위

합성 관절 좌표로 펴짐/굽힘, 미검출, 작은 손, 화면 가장자리, 측면, 지속 시간 및 단계 전환을 테스트한다. 합성 테스트 통과는 실제 수어 교정 정확도가 아니다. 실제 웹캠에서 정상 오교정·오류 누락과 가림·동작 전환을 추가 확인해야 한다. 수어 전문가 검증 또는 최종 테스트가 완료됐다고 주장하지 않는다.
